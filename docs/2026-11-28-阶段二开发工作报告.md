# 2026-11-28 阶段二开发工作报告

## 工作范围

本轮按照 [产品路线图](./PRODUCT_ROADMAP.md) 的阶段二，推进客户端接入和 MCP 目录使用体验。
功能改动已在本地提交 `9d4b183`（`feat: add client integration and catalog checks`）；
本报告单独提交。此前迁入产品路线和配置迁移说明的提交是 `8d99277`。

项目仍以 Windows 本地运行为目标。阶段二目前**部分完成**：接入和目录检查的基础功能已经实现，
但真实客户端连接与真实 Agent 目录评测尚未全部完成。

## 做了什么

### 1. 客户端接入

- 新增 Claude Code、Codex、OpenCode 2.x 和 Cursor 的配置适配，支持查找配置、接入、更新、
  移除和单步回滚。适配器编辑 JSONC 或 TOML 时保留其他配置和注释。
- 新增 `connect status|install|verify|uninstall|rollback` 命令，以及管理面板中可折叠的
  “客户端一键接入”区域。可以选择独立代理、指定配置或分组，也可以通过 `--attach` 连接
  已运行的共享代理。
- 接入前实际启动代理并通过 stdio 检查 MCP 握手和四个元工具；检查失败时不写客户端配置。
  这一步只证明代理能够响应，不能证明客户端内部已经连接或成功调用工具。
- 默认拒绝覆盖不属于本项目的同名条目；明确选择替换才会继续。修改前备份完整客户端配置，
  写入采用锁和原子替换；回滚前检查当前文件和备份，防止覆盖后续修改。备份可能包含私人配置，
  使用时需要妥善保管。
- 安装、回滚和面板交互使用隔离配置测试；实际浏览器检查只查看页面，没有点击真实客户端配置写入操作。

具体用法与限制见 [本地客户端接入](./CLIENT_INTEGRATION.md)。

### 2. 服务器目录检查与评测基础

- 新增 `catalog check`，只读统计服务器描述长度、标签、示例和目录预算。它不展开密钥、不连接
  下游服务器，也不修改配置。描述过短只提示人工复查，不代表程序已判断描述是否准确。
- 对当前默认配置的只读检查得到 19 个服务器、其中 13 个启用；14 条描述少于 20 字，后续需要
  人工检查用途和能力边界。这个统计不代表这些服务器已全部连接或通过功能测试。
- 新增目录描述编写说明，以及包含 8 个合成服务器、18 个任务的评测集。出题脚本不会把标准答案
  放进给 Agent 的提示；评分脚本检查答案并列出错题。目前还没有真实 Agent 作答结果或准确率。

具体规则和评测命令见 [服务器目录说明与评测](./CATALOG_GUIDE.md)。

### 3. 测试与文档

- 增加配置编辑、冲突保护、备份与回滚、代理握手、管理 API、面板交互和目录检查相关测试；
  测试覆盖实际 attach 握手，以及异常和拒绝覆盖的情况。
- 更新 README、架构文档、技术路线图和产品路线图，新增阶段实施记录及使用说明。路线图明确
  把阶段二标为部分完成，没有将市场或资源分级当成已实现。
